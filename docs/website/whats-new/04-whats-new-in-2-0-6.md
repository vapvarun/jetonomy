# What's New in 2.0.6

A dedicated update server. Jetonomy and Jetonomy Pro now get their updates and licence checks from updates.wbcomdesigns.com, and fall back to wbcomdesigns.com on their own if it cannot be reached.

> **Note:** Jetonomy and Jetonomy Pro are released together. Jetonomy Pro 2.0.6 requires Jetonomy 2.0.6, so update both at the same time.

## Updates and licences

- **Update server.** Update checks, downloads and licence checks use updates.wbcomdesigns.com.
- **Automatic fallback.** If the update server cannot be reached, Jetonomy retries wbcomdesigns.com straight away, so updates keep working.
- **Nothing to set up.** Your licence key, activated sites and settings are unchanged.

## What's new in Pro

- Licence activation, deactivation and the weekly licence check use the same update server and fallback. No change to Pro features.
