# Security review: Jetonomy 2.0.5

Scope: everything shipped since v2.0.4. Product code is unchanged; the changes are the bundled licensing SDK
(`libs/edd-sl-sdk`, now our `1.0.4-wbcom.2`), the new update-signature module (`libs/package-signatures` 1.0.1)
and its registration in `jetonomy.php`.

## G1 mechanical sweep

`security-sweep.sh . --baseline v2.0.4`: identical counts to 2.0.4 (no new findings in own code; `libs/` is out of
the sweep's scope and reviewed below). No CRITICAL patterns.

## G2 authorisation

No REST route, AJAX action or capability changed. `audit-rest-routes.php` OK for free and Pro.

## G3 reviewed diff

- `libs/package-signatures`: hooks `upgrader_pre_download` at `PHP_INT_MAX` for registered plugins only. Checks the
  Ed25519 signature (sodium, `sodium_compat` fallback), product, version (offered and newer than installed), size and
  SHA-256 of the downloaded file. Insecure or off-list package hosts are refused in enforce mode and logged in warn
  mode; a file supplied by an earlier handler is checked too. Downloads use `wp_safe_remote_get` streamed to
  `wp_tempnam`; the bundle is capped at 8 KB. Reviewed during the signed-updates work: two fail-open paths (an
  untrusted host and an earlier handler's file) were found and fixed before 1.0.0 was tagged. 1.0.1 (this release):
  an incomplete bundled copy is skipped instead of a fatal error (found by the Step 8 degrade check; regression test
  `tests/boot-test.php` fails on 1.0.0).
- `libs/edd-sl-sdk`: our patches over EDD 1.0.4: an API failure no longer reaches the updater as a non-object; each
  bundled copy loads its own classes (the newest copy runs); symlink-safe asset URLs. No new endpoints or options.
- Mode is warn for this release: a bad or missing signature is logged (option `package_signatures_log`, not
  autoloaded, last 20) and the update installs as before.

## Scanner-visible but safe

- `wp_safe_remote_get` to the store's fallback URL: host fixed by registration, https only.
- `$GLOBALS['package_signatures_*']`: registration registry, written only by bundled code.

## Not blocking, recorded

- Pre-existing combo-suite failures (4, Pro tests, code unchanged since 2.0.4): see the release notes to the owner.
